Mikroservis Siparis Yonetim Sistemi

Tum istekler API Gateway (:8080) uzerinden gecer — asagidaki gunlukte hangi servise gittigini gorebilirsin

1 · Kimlik user-service :8082

Parola BCrypt ile hash'lenir, giriste JWT uretilir.

2 · Urunler product-service :8081

Kendi PostgreSQL veritabaninda tutulur. Token gerektirmez.

3 · Siparis ver order-service :8083

Projenin kalbi: tek bir istek, arka planda 3 servise REST cagrisi tetikler.

4 · Siparisler order-service :8083

Siparis kaydi, kullanici ve urun bilgisinin kopyasini tutar — servisler arasi JOIN yoktur.

5 · Bildirimler notification-service :8084

Kritik olmayan servis: kapali olsa bile siparis basariyla olusur.

6 · Hata senaryolari

Mikroserviste asil zor kisim hatalarin dogru kodla donmesi. Dene ve gunlukteki HTTP kodlarina bak.

Neden onemli? 404 "sen yanlis istedin", 502 "karsi servis coktu" demek. Ikisini karistirirsan hata ayiklamak imkansiz hale gelir.

Canli istek gunlugu

Tarayicidan yapilan her HTTP cagrisi. "Servis" sutunu, Gateway'in istegi hangi mikroservise yonlendirdigini gosterir.
